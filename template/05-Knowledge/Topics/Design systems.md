# Design systems

What I've learned building one at Northwind Studio with [[Freja Nørgaard]].

1. Tokens first, components second.
2. Name things by intent (`color.text.muted`), never by value (`grey-500`).
3. A component without docs doesn't exist.

Further reading: [[The Design of Everyday Things]], [[Thinking in Systems]].
